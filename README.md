# 文献カード検索（bibcard）

読んだ論文や本を「文献カード」として登録し、キーワードで探せるようにする小さなツールです。卒論・大学院の文献整理にも使えます。

## 使い方

- **登録**：タイトル（必須）・著者・年・出典・キーワード・メモを入力して登録します。
- **検索**：検索欄に語を入れると、タイトル・著者・キーワードのいずれかに部分一致するカードだけが表示されます。空欄なら全件表示です。
- **削除**：各カードの「削除」ボタンから消せます（確認ダイアログ付き）。

検索は登録済みカードへの単純な部分一致のみで、外部AIや外部データベースは使いません。

データは SQLite に保存されます。DB のパスは環境変数 `BIBCARD_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- 書誌情報の自動取得（DOI 検索など）はありません。全て手入力です。
- 検索は部分一致のみで、あいまい検索や関連文献の提案はしません。
- 編集機能はありません（直したい場合は削除して登録し直してください）。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
